# SS / VMess 节点导入与订阅

当前对话中曾公开的第三方节点密码/UUID应先在提供商处轮换。不要把原始链接复制到代码、PR、CI、截图或文档。在正式 HTTPS 面板输入重新签发的数据；没有安全的新凭据时，本次不执行真实导入，也不报告节点在线。

## 导入与管理

Owner/Admin 在管理后台「节点源 / 分配」可直接点击「新增节点」「批量导入」「新增订阅源」，无数据或搜索无结果时仍有可点击入口。用户前台「节点订阅」复用同一管理模块，个人来源仍按所有者隔离。新增、编辑、启停、删除、分配和撤销均调用真实 API。

「批量导入」支持 SS SIP002、旧式整串 Base64、订阅 Base64、URI 编码、VMess Base64 JSON 与直接 VMess JSON，保留原始名称、IEPL/IPLC、倍率和下载专用标签。地区按名称/旗帜识别，可编辑修正，不代表出口实测。

VMess 保留 UUID、AlterID、加密方式、TLS/SNI、TCP/WebSocket、Host 与 Path。SS AEAD-2022 使用非 Base64 userinfo 导出。不支持的传输/插件、未知 TLS 配置及不安全证书跳过配置明确失败；不能为了「导入成功」静默改变连接参数。当前不承诺 gRPC/Reality/SS 插件兼容。

相同连接参数去重，并保留原名称别名与标签；同名但连接不同的节点继续保留，避免删除有效资源。预览显示解码后的原始条目数、有效/重复/失败数量、地区及协议统计与失败行号，错误信息不含原文。有效节点以信封加密保存；解析失败的原始内容不入库、不输出日志。

节点支持批量导入、编辑名称/标签/地区/分组、替换本地节点连接、软删除和启停。远程订阅的连接参数由上游管理，刷新保留用户的启停、分组与删除覆盖。所有连接初始为 PENDING_VERIFICATION；DISABLED 表示停用，PARSE_FAILED 表示解析失败。没有真实检测时延迟/流量为 null，不显示伪造测量值。

## 订阅 URL 与动态刷新

「新增订阅源」接收 HTTPS 订阅 URL 或本地节点内容。远程 URL 以加密凭据保存，列表和编辑界面不回显；修改名称、分组、地区或授权说明无需再次输入 URL。保存远程来源会排队同步，之后可手动刷新；刷新任务去重，失败时保留上一版节点和已生效的用户设置，并显示脱敏失败状态。只有解析与持久化全部成功才替换节点，源在同步期间被编辑、停用或删除时，旧任务不得覆盖更新。

远程获取遵循现有 SSRF 防护，仅允许安全的 HTTPS 目的地址；内网、回环、云元数据、重定向越界或不受支持的端口会失败。不要把 URL 放在查询参数、截图、工单或 CI 输入中。

## 第三方授权与订阅隔离

第三方批量导入仅限 Owner/Admin，并须同时确认聚合授权、再分发许可及提供授权依据。系统保存声明，不能替用户审查提供商合同或自动证明第三方授权。没有再分发授权的第三方源不能新建共享授权，既有旧订阅路径同样受当前授权检查，不因兼容而绕过权限。

管理员在「分配 / 撤销授权」中查看当前授权，仅向有效用户分配本人有权再分发的来源；撤销后可重新分配。全局摘要不授权管理员读取其他用户的连接密钥或改写其私人来源。

用户只取得自己拥有或由管理员明确授权、仍有效的源；源所有者停用、授权撤销、节点停用或删除会立即影响导出。每用户独立 Token，可轮换/撤销；按国家、协议、分组筛选在服务端执行，对新旧地址都有效。

管理员可配置每个普通用户的节点数量上限、订阅开关和流量额度策略。当前没有节点侧或提供商流量回传：已用流量为 null，计量状态为 UNAVAILABLE，流量额度执行状态为 NOT_ACTIVE。流量额度只保存待接入策略，尚不限制 VPN 实际流量；节点数量与订阅授权检查已经在服务端生效。不能把订阅下载次数、节点数或模拟数值算作流量。

URI / Base64 输出面向 Shadowrocket / v2rayN 等客户端；格式往返测试只验证参数保留，不等于真机导入或节点可连接。真实客户端测试需要轮换后的凭据、客户端和用户操作条件，未完成时必须注明未验收。

离线校验工具只从 stdin 读取，输出计数、地区/协议分布和失败行号，不输出节点名、原始 URI、密码或 UUID：

```bash
pnpm nodes:validate < 受保护的本地节点文件
```

工具不连接节点，connectivity 永远标明 NOT_TESTED。生产导入请使用面板，不将敏感输入交给 CI。

## 46 条清单的验收准备

用户提供的人工盘点为 34 条 SS、12 条 VMess，尚未经本环境取得轮换后的原文进行真实解析。CI 仅使用 46 条无真实凭据的合成节点测试数量、去重与格式；不能把该结果作为真实清单导入记录。正式导入前由 Owner 核对使用、聚合与再分发授权，在受信 HTTPS 表单输入重新签发的 URI，预览真实总数/有效/重复/失败及地区协议分布，确认后加密入库。新节点均待真实验证，真实客户端导入及连通测试另行验收，不上传敏感截图。
