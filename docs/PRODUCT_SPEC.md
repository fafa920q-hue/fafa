# 产品规格与能力边界

用户端：仪表盘、节点订阅、Codex、服务器、位置中心、我的账户。手机底部固定五项主导航，位置中心通过概览卡片与我的账户进入。管理端：概览、用户/邀请、节点源/分配、服务器授权、AI 连接状态、任务队列、安全审计、系统设置/备份。

Owner 可管理所有非秘密摘要、邀请 Admin、调整角色和席位。Admin 可邀请 Member / Viewer、禁用成员、撤销会话、授权自己拥有的共享源和服务器。Member 只能管理个人资源与获授权资源。Viewer 只读，不能创建源、切换 AI 账户或打开终端。Owner 禁止从网页被降权 / 禁用，防止锁死。

默认 20 个注册席位（禁用账号仍占席位），激活通过事务锁避免竞态。邀请只登记，不自动发邮件。账号以 Google sub 绑定，邮箱仅用于首次邀请匹配。无 Google 凭据时只在显式 development 开发开关下模拟登录；生产硬拒绝。

订阅：源 CRUD / 启停 / 远程刷新入队、历史、个人源与共享源聚合、完整身份去重、按国家出口筛选、可撤销独立 Token、4 种输出格式。配额支持用户节点导出数量上限与订阅启用开关（API）；每位用户源配额、流量额度与下载配额管理界面仍待细化。未知流量、实时在线与延迟不会伪造。真实节点健康探测与流量计量尚未接入。

协议矩阵：VLESS / VMess / Trojan / Shadowsocks / Hysteria2 基础节点，TCP / WS、严格 TLS、SNI、WS path / Host。输入：URI / Base64、Mihomo proxies、sing-box outbounds。输出：URI / Base64 / Mihomo YAML / sing-box JSON。自动化覆盖规范化往返；不是客户端全版本认证。Reality、gRPC、SS 插件、hy2 混淆、特殊扩展或跳过 TLS 验证不在承诺范围，部分高级结构须继续补充 fail-closed 校验。支持矩阵应随实际客户端测试扩展，不能宣传所有协议通用。

API 工作台支持加密多个 API 账户、切换、队列任务、持久输出、SSE、取消与最近任务恢复。没有 API Key / 演示状态不能创建真实外部任务。ChatGPT 托管授权未批准，按钮禁用。官方 Codex Cloud 仅外链。

SSH 支持加密 key/password、受控公网白名单、首次指纹确认、变更拒绝、短期单次票据与 Cookie 双验证、WS 通道、并发 2、闲置 5 分钟关闭。默认只读 uptime 诊断；明确开启交互 shell 后，双重批准授予当前会话远程账户权限。不是逐条命令沙箱，生产推荐继续只读。暂不支持内网、passphrase 私钥、自动 agent 或浏览器任意网络探测。

位置中心保存用户坐标，按授权节点国家筛选订阅。预览是坐标示意图，不是实际地图；没有在线城市搜索、地理编码或地图 SDK。iOS GPS 修改暂不支持，小火箭只提供手动导入指引，未验证 iOS 26.3 真机。

账户支持会话列表/撤销、脱敏数据导出、删除请求登记。删除与保留期清理需管理员运维处理，尚未自动硬删除。管理端 MFA 仅预留扩展，不声称已实现二次认证。
