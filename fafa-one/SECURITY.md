# 安全状态：本地核心已验证，生产门禁阻断

个人连接使用 AES-256-GCM、独立部署密钥、随机 nonce 和 owner/connection 关联数据。服务端从不回传原始密钥，管理员个人数据接口也按 owner 拒绝跨用户访问；验证错误不包含原始输入；供应商异常统一脱敏，普通日志只记录路径/状态/时间，不记录请求体和 Authorization。SQLAlchemy 参数日志关闭。备份恢复需要独立保管加密密钥；本候选尚无密钥轮换工具。

连接撤销/删除擦除数据库中的密文并请求停止运行；历史费用和审计保留。它不撤销供应商 API Key，也不清除已有备份。供应商撤销必须由账户所有者在官方渠道操作。

继承本地可撤销会话、Argon2id、CSRF、速率限制、管理员服务端角色检查、不可公开初始化管理员流程。现有 Cookie 为 Host-only/HttpOnly，生产要求 Secure；但是独立 admin session audience、强制 MFA/Passkey、不可篡改审计、账号绑定重验仍未完成，旧 API 不具备新的完整生产管理安全保证。

`APP_ENV=production` 明确拒绝启动本 alpha。禁止将 development 配置用于公网生产以绕过门禁。正式版本需要代码评审、真实身份与租户隔离验收、生产迁移恢复演练及独立管理员安全实现后移除此阻断。

未启用附件/知识库、任意插件、任意工作流、终端 Web 执行入口，不用空按钮假装已支持；对应安全功能也未验收。基础请求体限制仍来自已有应用/反向代理；完整上传扫描和类型解析尚未实现。

依赖扫描零已知漏洞仅描述扫描时已公布的问题，不等于完整安全审计。Open WebUI 品牌条款、LiteLLM enterprise 边界和 sing-box 附加条款需单独评审；未把它们安装到本候选中。
