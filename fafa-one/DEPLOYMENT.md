# 尚未生产发布

本版本不能部署到 fafa888.uk 或 a.fafa888.uk。不要把归档源码当成当前生产版本，不要对现网运行归档迁移。APP_ENV=production 拒绝启动是预期门禁，不是需要用 development 绕过的故障。

已验证本地前端构建、后端启动、容器镜像构建与隔离 PostgreSQL。尚未登录目标服务器，不能报告其 Linux/CPU/内存/磁盘/端口、防火墙、内部服务暴露、证书来源及访问日志配置。云端开发机的资源不是生产服务器资源。

恢复工作前需要已授权部署通道（含主机身份核验资料或现有受控 CI 通道）、实际生产 Git 与未提交修改清单、只读数据库 schema/配置映射及可恢复备份、DNS/证书控制方式、独立测试环境，以及按需配置的 SMTP、官方 OAuth、个人测试 AI 和 CLI 设备授权。不要在聊天、仓库或日志里粘贴这些秘密；使用部署环境秘密绑定。

完整发布流程仍应是：确认生产基线并保存标签 → 备份及独立恢复对账 → 对真实 schema 设计增量迁移 → staging 构建与部署 → 全部需求验收与安全门禁 → 精确双域名配置 → 发布及真实冒烟 → 错误监控 → 正式发布标签和可用回滚路径。当前没有执行其中任何生产变更。

Compose 只是开发/隔离容器的来源模板，数据库和 API 没有宿主机公开端口，Web 仅回环绑定。它没有提供完整管理域名和 MFA 部署。没有更改与本项目无关的服务或 DNS。
